01 — About Me

I'm Xolarus, an aspiring cybersecurity researcher interested in understanding software at its lowest levels.

My main interests lie in reverse engineering, binary analysis, assembly language, and low-level software behavior. I want to understand not only what a program does, but also how it works internally — from compiled instructions to memory and execution flow.

I'm currently improving my C++ skills, learning assembly, and exploring reverse engineering with Ghidra.

I also have experience reading and understanding scripts written in Python and Lua, and I'm gradually expanding my knowledge of both languages.
