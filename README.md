About Me

I'm Xolarus, an aspiring cybersecurity researcher with a particular interest in reverse engineering and low-level software.

I'm fascinated by what happens beneath the surface of a program: how compiled code works, how instructions are executed, how memory is managed, and how understanding these mechanisms helps reveal the inner workings of software.

Currently, I'm improving my C++ skills, learning assembly language, and exploring binary analysis with Ghidra.

My approach is simple: understand the fundamentals, investigate how things work, and keep pushing my technical knowledge further.

Primary interest: Cybersecurity and reverse engineering
Main language: C++
Reverse engineering: Ghidra
Currently learning: Assembly and computer architecture
Additional experience: Reading and understanding Python and Lua scripts
The deeper you look, the more there is to understand.
